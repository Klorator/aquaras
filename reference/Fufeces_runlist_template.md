# Fu feces runlist template

Workbook object from openxlsx2. Builds an .xlsx file acting as a
template for building a runlist that will be compatible with
[`ras.Fu_feces_workflow()`](https://klorator.github.io/aquaras/reference/ras.Fu_feces_workflow.md).

## Usage

``` r
Fufeces_runlist_template
```

## Format

A workbook object from openxlsx2
