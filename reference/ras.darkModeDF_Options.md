# Options for data frame style

Sets `reactable.theme` in
[`base::options()`](https://rdrr.io/r/base/options.html) with CSS
styling borrowed from the [Reactable example
documentation](https://glin.github.io/reactable/articles/examples.html#theming)

## Usage

``` r
ras.darkModeDF_Options()
```
